Work From Home Checklist
Prepare your workspace, communication and daily routine.

Workspace and equipment
[ ] Set up a comfortable, usable work area.
[ ] Test internet, audio and required applications.
[ ] Follow employer requirements for secure access and device use.

Communication
[ ] Agree working hours, availability and response expectations.
[ ] Know how to ask for help and report progress.
[ ] Keep shared tasks, notes and deadlines current.

Workday routine
[ ] Choose a short priority list for the day.
[ ] Plan focused work periods and breaks.
[ ] Check progress and hand over unfinished work clearly.
[ ] Set a clear end-of-day routine.
